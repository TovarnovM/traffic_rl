# v1.1 — Physica A reproduction materials

- Current Graph/NodeMLP/GridCNN simulator, training, MC and statistical source code.
- Fifteen training configurations; frozen policy selection, seeds and diagnostic profiles.
- Seventeen selected plus fifteen terminal weight bundles: 28 unique numerical NPZ/JSON bundles.
- All 38 final figures, five main and five supplementary tables, and 42-domain results.
- Compact aggregate/diagnostic/trace inputs and portable publication generators.
- Explicit local MC-to-statistics ingestion; no private cluster service required.

The scope is the current Physica A study only. Manuscript text, correspondence, raw archives, logs, intermediate checkpoints and the separate/joint RL study are excluded from this release tree.

Preparation used static inspection and file/metadata integrity checks only. No tests, experiments, plots, builds or dependency installation were run. Numerical redraw and new experimental runs remain runtime-unvalidated; the original vector schematic is retained as a master rather than claimed as a numerical redraw. Bitwise retraining/resume is not promised. Older Git history is unchanged.
