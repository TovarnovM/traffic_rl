normalize_pos semantics
-----------------------
For ring length L:

    normalize_pos(pos) = pos mod L

Examples for L = 10:
- normalize_pos(0) == 0
- normalize_pos(9) == 9
- normalize_pos(10) == 0
- normalize_pos(12) == 2
- normalize_pos(-1) == 9
- normalize_pos(-11) == 9

For ndarray input:
- Return a NumPy ndarray.
- The returned values must be normalized elementwise.
- It is acceptable if NumPy chooses the output integer dtype.
- Do not require C-contiguity here; topology helpers should work on ordinary integer arrays.

forward_distance semantics
--------------------------
This is the non-negative distance when moving forward along the ring from from_pos to to_pos.

For ring length L:

    forward_distance(from_pos, to_pos) = (to_pos - from_pos) mod L

The result is in:
    [0, L - 1]

Examples for L = 10:
- forward_distance(0, 0) == 0
- forward_distance(0, 1) == 1
- forward_distance(1, 0) == 9
- forward_distance(8, 1) == 3
- forward_distance(9, 0) == 1
- forward_distance(2, 7) == 5

Inputs may already be outside [0, L); compute using periodic semantics anyway:
- forward_distance(11, 13) == 2 for L = 10.
- forward_distance(-1, 1) == 2 for L = 10.

For ndarray input:
- Support elementwise NumPy broadcasting naturally where possible.
- Return a NumPy ndarray.

signed_delta semantics
----------------------
This is the shortest signed displacement from from_pos to to_pos on the ring.

Rules:
- Positive means moving forward is the shortest direction.
- Negative means moving backward is the shortest direction.
- Zero means same normalized position.
- Compute from forward distance d = forward_distance(from_pos, to_pos).
- If d > length / 2, return d - length.
- Otherwise return d.
- For exact half-ring ties when length is even, keep the positive value.

Examples for L = 10:
- signed_delta(0, 0) == 0
- signed_delta(0, 1) == 1
- signed_delta(1, 0) == -1
- signed_delta(9, 1) == 2
- signed_delta(1, 9) == -2
- signed_delta(0, 5) == 5
- signed_delta(0, 6) == -4

Examples for L = 9:
- signed_delta(0, 4) == 4
- signed_delta(0, 5) == -4

For ndarray input:
- Support elementwise NumPy broadcasting naturally where possible.
- Return a NumPy ndarray.
