# Goal

Add a small, explicit runtime invariant validation helper and a broad random-rollout test suite around the current reference core.

This task must **not** add new simulation physics.

This task must **not** change lane-change or longitudinal behavior.

The purpose is to make future optimized backend work safer by centralizing the invariants that every backend must preserve.

High-level goal:

```python
validate_runtime_invariants(state, params, topology) -> None
```

This helper should validate that a `TrafficState` is internally consistent after initialization or after any reference step.

# Required invariants

`validate_runtime_invariants(...)` must check at least the following.

1. Basic schema validity

---

Call:

```python
validate_state(state, params)
```

This should keep existing dtype, shape, alive-mask, and state-level validation centralized.

2. Topology compatibility

---

For current reference implementation, only periodic `RingTopology` is supported.

Check:

```text
topology.num_lanes == params.num_lanes
topology.length == params.road_length
```

Raise `ValueError` with a clear message if mismatched.

Do not implement open-boundary support.

3. Occupancy validity

---

Build occupancy:

```python
occupancy = build_occupancy(state, params)
```

This should reject duplicate alive head cells using existing indexing logic.

Then check:

```python
occupied_count = int((occupancy >= 0).sum())
alive_count = int(state.alive.sum())
```

Required:

```text
occupied_count == alive_count
```

Because current occupancy is head-cell-only, every alive vehicle occupies exactly one cell.

4. Alive lane range

---

For alive vehicles:

```text
0 <= state.lane < params.num_lanes
```

5. Alive position range

---

For alive vehicles:

```text
0 <= state.pos < params.road_length
```

6. Alive velocity range

---

For alive vehicles:

```text
state.vel >= 0
```

For uncontrolled alive vehicles:

```text
state.vel <= params.vmax_default
```

For controlled alive vehicles:

```text
state.vel <= params.vmax_controlled
```

Important: controlled vehicles do not yet receive external RL actions. `vmax_controlled` is only a velocity limit in the current reference logic.

7. Lane-change flag consistency

---

For alive vehicles:

```python
state.changed_lane == (state.last_lane_delta != 0)
```

All `last_lane_delta` values should be in:

```text
-1, 0, +1
```

It is acceptable to check this for all vehicles, not only alive vehicles.

8. Inactive vehicle no-change convention

---

Inactive vehicles should not report a lane change.

For inactive vehicles:

```text
changed_lane == False
last_lane_delta == 0
```

This matches the current no-change convention.

9. Indexing consistency

---

After building occupancy, also build lane ordering and neighbors:

```python
lane_order, lane_counts, lane_rank = build_lane_order(
    occupancy,
    n_vehicles=state.n_vehicles,
)

front_index, front_gap, back_index, back_gap = compute_neighbors(
    state,
    lane_order,
    lane_counts,
    lane_rank,
    topology,
)
```

The invariant helper does not need to deeply validate every neighbor relationship manually yet.

But it must at least ensure these calls succeed on the current state.

Additionally check basic shape consistency:

```text
front_index.shape == (state.n_vehicles,)
front_gap.shape == (state.n_vehicles,)
back_index.shape == (state.n_vehicles,)
back_gap.shape == (state.n_vehicles,)
```

10. Length ignored intentionally

---

Do not add any invariant that assumes body-cell occupancy.

Do not check that buses occupy multiple cells.

Do not reject states where bus bodies would overlap if length-aware geometry existed.

Current rule:

```text
one alive vehicle = one occupied head cell
```

This is intentional for now.
