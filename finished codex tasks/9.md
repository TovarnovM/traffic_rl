# Important composition issue

`step_longitudinal_reference(...)` currently resets:

```python
changed_lane[:] = False
last_lane_delta[:] = 0
```

This is correct for a standalone longitudinal-only phase.

But `step_reference(...)` must preserve the lane-change flags from the lane-change phase.

After a full step, these fields must describe lateral movement that happened during this full step:

```python
state.changed_lane
state.last_lane_delta
```

Future observation builders will use these fields as recent lane-changing behavior.

# Correct composition

Implement `step_reference(...)` like this:

```python
after_lc = step_lane_change_reference(state, params, topology, rng)

changed_lane = after_lc.changed_lane.copy()
last_lane_delta = after_lc.last_lane_delta.copy()

after_long = step_longitudinal_reference(after_lc, params, topology, rng)

out = after_long.copy()
out.changed_lane = changed_lane
out.last_lane_delta = last_lane_delta

validate_state(out, params)
build_occupancy(out, params)

return out
```

A final `out.copy()` after longitudinal is acceptable and preferred for clarity/safety.

Do not create a new rng inside `step_reference`.

Do not seed anything inside `step_reference`.

Use the same caller-provided `rng` object for both phases.

# Important composition issue

`step_longitudinal_reference(...)` currently resets:

```python

last_lane_delta[:] = 0
```

This is correct for a standalone longitudinal-only phase.

But `step_reference(...)` must preserve the lane-change flags from the lane-change phase.

After a full step, these fields must describe lateral movement that happened during this full step:

```python

state.last_lane_delta
```

Future observation builders will use these fields as recent lane-changing behavior.

# Correct composition

Implement `step_reference(...)` like this:

```python
after_lc = step_lane_change_reference(state, params, topology, rng)

changed_lane = after_lc.changed_lane.copy()
last_lane_delta = after_lc.last_lane_delta.copy()

after_long = step_longitudinal_reference(after_lc, params, topology, rng)

out = after_long.copy()

out.last_lane_delta = last_lane_delta

validate_state(out, params)
build_occupancy(out, params)

return out
```

A final `out.copy()` after longitudinal is acceptable and preferred for clarity/safety.

Do not create a new rng inside `step_reference`.

Do not seed anything inside `step_reference`.

Use the same caller-provided `rng` object for both phases.
