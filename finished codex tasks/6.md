Current indexing API and contract
=================================
Task 5 implemented:

    build_occupancy(state, params) -> occupancy
    build_lane_order(occupancy, *, n_vehicles) -> lane_order, lane_counts, lane_rank
    compute_neighbors(state, lane_order, lane_counts, lane_rank, topology) -> front_id, back_id, front_gap, back_gap

Indexing semantics:
- occupancy marks HEAD CELLS ONLY.
- occupancy[lane, head_pos] = vehicle array index.
- occupancy stores vehicle array indices, not vehicle_id values.
- inactive vehicles are ignored by occupancy/lane_order/neighbors.
- duplicate alive head cells are rejected.
- lane_order stores vehicle array indices ordered by increasing pos.
- lane_rank[i] is the rank of vehicle i inside its lane.
- front/back neighbors are same-lane only.
- lanes with 0 or 1 alive vehicle return front_id/back_id/front_gap/back_gap = -1.
- front_gap/back_gap are head-cell empty gaps.
- state.length is ignored in occupancy and gaps for now.

Do not change these semantics in this task.

Operational longitudinal semantics
==================================
All alive vehicle updates must be based on the OLD state and OLD indexing from the beginning of the step.

Do not update vehicles sequentially in a way that later vehicles see earlier vehicles' new positions.

The update order is:

1. validate state and topology;
2. build occupancy;
3. build lane_order/lane_counts/lane_rank;
4. compute front_id/back_id/front_gap/back_gap;
5. compute new velocities for all alive vehicles from old state;
6. clamp velocities for collision avoidance;
7. commit new positions simultaneously;
8. validate returned state;
9. optionally rebuild occupancy after movement to assert no duplicate head cells.

Detailed velocity rule
----------------------
For each alive vehicle i:

    old_v = int(state.vel[i])
    vmax_i = params.vmax_controlled if state.controlled[i] else params.vmax_default

    if front_id[i] == -1:
        gap_i = params.road_length - 1
        leader_v = vmax_i
    else:
        gap_i = int(front_gap[i])
        leader_v = int(state.vel[front_id[i]])

Important:
- gap_i is a head-cell empty gap.
- state.length is ignored.
- for a one-vehicle lane, front_id == -1, so the vehicle behaves as if it has free road.

Velocity phases:

Phase A — acceleration:

    v = min(old_v + 1, vmax_i)

Phase B — conservative anticipation / perspective:

This repo does not yet have paper-exact Revised S-NFS formulas. Implement a conservative anticipation rule that cannot create collisions:

    if front_id[i] != -1 and gap_i <= params.G:
        anticipated_leader_motion = max(leader_v - params.S, 0)
        anticipated_gap = gap_i + anticipated_leader_motion
        v = min(v, anticipated_gap)

This gives a simple same-lane anticipation effect while remaining safe.

Phase C — slow-to-start:

If the vehicle was stopped and has proposed v > 0, it may fail to start.

Use params.r as the probability of applying the slow-to-start delay:

    if old_v == 0 and v > 0:
        if rng.random() < params.r:
            v = 0

Rationale:
- This gives params.r a concrete role.
- Tests can set r=0.0 to disable slow-to-start deterministically.
- Tests can set r=1.0 to force slow-to-start deterministically.

Phase D — random braking:

If v > 0, apply a simple random braking probability derived from local traffic state.

Use:
- params.P4 as the base random braking probability on free road;
- 1.0 - params.P3 as the braking probability when within params.G of a leader;
- 1.0 - params.P2 as the braking probability when stopped-start interaction is not active but traffic is close;
- keep params.P1 unused for now only if there is no clean role, but document that exact paper-equation mapping is deferred.

Concrete rule:

    brake_prob = params.P4
    if front_id[i] != -1 and gap_i <= params.S:
        brake_prob = max(brake_prob, 1.0 - params.P2)
    elif front_id[i] != -1 and gap_i <= params.G:
        brake_prob = max(brake_prob, 1.0 - params.P3)

    if v > 0 and rng.random() < brake_prob:
        v -= 1

Rationale:
- With defaults P2=0.99, P3=0.98, P4=0.01, stochastic braking remains rare.
- Tests can disable random braking by setting P2=1.0, P3=1.0, P4=0.0.
- Tests can force braking with P4=1.0.

Phase E — collision avoidance hard clamp:

Always enforce:

    if front_id[i] != -1:
        v = min(v, gap_i)

Then enforce:

    v = max(0, min(v, vmax_i))

This hard clamp is mandatory. It is the final safety net and must make duplicate occupied head cells impossible when starting from a valid head-cell state.

Commit positions
----------------
For each alive vehicle i:

    new_pos[i] = topology.normalize_pos(int(state.pos[i]) + int(new_vel[i]))

Inactive vehicles:
- keep pos and vel unchanged.

After position commit:
- call validate_state on the new state;
- build occupancy on the new state to ensure duplicate head cells are rejected if a bug exists.

This is acceptable for the current head-cell-only model.
