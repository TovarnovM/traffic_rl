```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Protocol

import numpy as np

from snfs_traffic.core.params import SimulationParams
from snfs_traffic.core.state import TrafficState
from snfs_traffic.core.step import step_reference
from snfs_traffic.topology import RingTopology


class StepBackend(Protocol):
    """Protocol for one full simulator step backend.

    Backends must implement the same semantics as step_reference.
    """

    name: str

    def step(
        self,
        state: TrafficState,
        params: SimulationParams,
        topology: RingTopology,
        rng: np.random.Generator,
    ) -> TrafficState:
        ...


@dataclass(frozen=True)
class ReferenceBackend:
    """Backend wrapper around the pure reference implementation."""

    name: str = "reference"

    def step(
        self,
        state: TrafficState,
        params: SimulationParams,
        topology: RingTopology,
        rng: np.random.Generator,
    ) -> TrafficState:
        return step_reference(state, params, topology, rng)


_REFERENCE_BACKEND = ReferenceBackend()


def get_reference_backend() -> ReferenceBackend:
    """Return the singleton reference backend."""
    return _REFERENCE_BACKEND
```

# Backend contract

The backend contract must be documented in `backend.py` docstrings and in README.

The contract:

```text
- A backend performs exactly one full simulation step.
- It must match step_reference semantics.
- It receives:
  - TrafficState;
  - SimulationParams;
  - RingTopology;
  - np.random.Generator.
- It returns a TrafficState.
- It must not use global NumPy RNG.
- It must consume randomness only from the provided rng.
- For the same initial state and same RNG seed, it must produce the same result as step_reference.
- It must preserve current head-cell-only semantics.
- It must preserve current lane-change flag semantics:
  changed_lane / last_lane_delta describe lateral movement during the returned full step.
- It must not implement controlled RL action semantics.
- It must not implement length-aware occupancy or body-cell collision geometry.
```

Important: do not try to solve future RNG stream compatibility for parallel/vectorized optimized backends yet. For now, the reference backend simply delegates to `step_reference`.

# Important testing detail: RNG equivalence

All equivalence tests involving stochastic lane changes must use two independent RNG objects created with the same seed:

```python
rng_ref = np.random.default_rng(seed)
rng_backend = np.random.default_rng(seed)
```

Do not reuse the same RNG object for reference and backend in the same comparison, because the first call would advance the RNG stream.

This is critical.
