# Pure-array kernel contract

The kernels should assume that public wrappers already validated high-level objects and dtype/shape constraints.

However, they should still preserve current runtime behavior for valid inputs.

## build_occupancy_kernel

Input:

```text
lane: int lane array, shape (n_vehicles,)
pos: int position array, shape (n_vehicles,)
alive: bool array, shape (n_vehicles,)
num_lanes: scalar int
road_length: scalar int
```

Output:

```text
occupancy: int32 array, shape (num_lanes, road_length), C-contiguous
```

Semantics:

```text
- initialize all cells to MISSING_INDEX;
- for each vehicle index i:
  - if alive[i] is False, ignore it;
  - otherwise write occupancy[lane[i], pos[i]] = i;
- if two alive vehicles occupy the same head cell, raise ValueError;
- do not mark body cells for length > 1;
- do not use vehicle_id;
- do not sort.
```

## build_lane_order_kernel

Input:

```text
occupancy: int32 array, shape (num_lanes, road_length)
n_vehicles: scalar int
```

Output:

```text
lane_order: int32 array, shape (num_lanes, road_length)
lane_counts: int32 array, shape (num_lanes,)
lane_rank: int32 array, shape (n_vehicles,)
```

Semantics:

```text
- lane_order is initialized with MISSING_INDEX;
- lane_rank is initialized with MISSING_INDEX;
- scan each lane by increasing position;
- every occupied head cell contributes its vehicle index to lane_order[lane, rank];
- lane_counts[lane] stores the number of occupied head cells in that lane;
- lane_rank[vehicle_idx] stores the rank of that vehicle in its lane;
- preserve the exact current ordering semantics.
```

## compute_neighbors_kernel

Input:

```text
lane: int lane array, shape (n_vehicles,)
pos: int position array, shape (n_vehicles,)
alive: bool array, shape (n_vehicles,)
lane_order: int32 array, shape (num_lanes, road_length)
lane_counts: int32 array, shape (num_lanes,)
lane_rank: int32 array, shape (n_vehicles,)
road_length: scalar int
```

Output:

```text
front_id: int32 array, shape (n_vehicles,)
back_id: int32 array, shape (n_vehicles,)
front_gap: int32 array, shape (n_vehicles,)
back_gap: int32 array, shape (n_vehicles,)
```

Semantics:

```text
- initialize ids with MISSING_INDEX;
- initialize gaps with MISSING_GAP;
- inactive vehicles remain missing;
- lane with <= 1 alive vehicle gives missing neighbors/gaps;
- for count >= 2:
  - front_rank = (rank + 1) % count
  - back_rank = (rank - 1) % count
  - front_id/back_id come from lane_order;
  - front_gap = periodic_forward_distance(pos[i], pos[front_id]) - 1
  - back_gap = periodic_forward_distance(pos[back_id], pos[i]) - 1
- periodic_forward_distance(a, b) is `(b - a) % road_length`;
- preserve current head-cell-only gap semantics exactly.
```
