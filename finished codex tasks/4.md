VehicleMix semantics
====================
VehicleMix controls initial vehicle categories.

Fields:
- av_fraction:
    Fraction of all vehicles that are AV-like.
- controlled_fraction:
    Fraction of all vehicles that are RL-controlled AVs.
- bus_fraction:
    Fraction of all vehicles represented as buses.
- bus_length:
    Length value assigned to bus vehicles.

Validation:
- av_fraction, controlled_fraction, bus_fraction must be numeric probabilities in [0.0, 1.0].
- bool values must be rejected.
- strings/None must be rejected.
- bus_length must be int and >= 1.
- bool bus_length must be rejected.
- Reject mixes where av_fraction + controlled_fraction + bus_fraction > 1.0.
- Raise ValueError with useful messages containing the relevant field name.

Category assignment rule:
- Every vehicle starts as HDV.
- Then assign disjoint categories using the mix probabilities:
    - controlled AV
    - non-controlled AV
    - bus
    - remaining HDV
- controlled_fraction is independent category mass, not a subset of av_fraction.
- Therefore:
      controlled_count ~= controlled_fraction * N
      av_count ~= av_fraction * N
      bus_count ~= bus_fraction * N
      hdv_count = N - controlled_count - av_count - bus_count
- To avoid stochastic count fluctuations in tests, compute counts deterministically:
      controlled_count = floor(controlled_fraction * N)
      av_count = floor(av_fraction * N)
      bus_count = floor(bus_fraction * N)
      hdv_count = N - controlled_count - av_count - bus_count
- If floor rounding leaves unused probability mass, do not compensate. Keep simple and deterministic.
- Shuffle category assignment with rng.permutation(N), so the positions/categories are reproducible for a seed but not sorted by category.

Suggested encoding:
- HDV:
    veh_type = HDV_VEH_TYPE
    behavior_id = HDV_BEHAVIOR_ID
    controlled = False
    length = 1
- AV:
    veh_type = AV_VEH_TYPE
    behavior_id = AV_BEHAVIOR_ID
    controlled = False
    length = 1
- controlled AV:
    veh_type = AV_VEH_TYPE
    behavior_id = CONTROLLED_AV_BEHAVIOR_ID
    controlled = True
    length = 1
- bus:
    veh_type = BUS_VEH_TYPE
    behavior_id = BUS_BEHAVIOR_ID
    controlled = False
    length = vehicle_mix.bus_length

Important:
- This task only stores bus length in the length field.
- Do not implement multi-cell bus occupancy.
- Do not implement bus-specific dynamics.

make_uniform_random_state semantics
===================================
Signature:

    def make_uniform_random_state(
        *,
        num_lanes: int,
        road_length: int,
        density: float,
        seed: int | np.integer,
        vehicle_mix: VehicleMix | None = None,
    ) -> TrafficState:
        ...

Input validation:
- num_lanes must be int and > 0.
- road_length must be int and > 0.
- bool values must be rejected even though bool is a subclass of int.
- density must be numeric and in [0.0, 1.0].
- bool density must be rejected.
- seed must be Python int or NumPy integer scalar.
- bool seed must be rejected.
- vehicle_mix=None means VehicleMix().

Vehicle count:
- capacity = num_lanes * road_length.
- n_vehicles = floor(capacity * density).
- density=0.0 returns a valid empty TrafficState with N=0.
- density=1.0 fills every cell exactly once.
- n_vehicles must never exceed capacity.

Position/lane sampling:
- Treat each cell as a flat integer in [0, capacity):
      flat_cell = lane * road_length + pos
- Sample n_vehicles unique flat cells without replacement:
      rng.choice(capacity, size=n_vehicles, replace=False)
- Decode:
      lane = flat_cell // road_length
      pos = flat_cell % road_length
- Shuffle order should be whatever rng.choice returns. Do not sort unless necessary.
- Head cells must be unique.

Initial velocity:
- For this task, initialize all velocities to 0.
- Do not randomize velocity yet. That belongs to future scenario presets.

Initial IDs:
- vehicle_id = np.arange(n_vehicles, dtype=np.int32)

Initial flags:
- alive = True for all generated vehicles.
- last_lane_delta = 0 for all vehicles.
- changed_lane = False for all vehicles.
- controlled according to VehicleMix category.

Array dtypes:
- vehicle_id: VEHICLE_ID_DTYPE / np.int32
- lane: LANE_DTYPE / np.int16
- pos: POSITION_DTYPE / np.int32
- vel: VELOCITY_DTYPE / np.int16
- length: LENGTH_DTYPE / np.int16
- veh_type: VEHICLE_TYPE_DTYPE / np.int16
- behavior_id: BEHAVIOR_ID_DTYPE / np.int16
- alive: BOOL_DTYPE / np.bool_
- last_lane_delta: LANE_DELTA_DTYPE / np.int8
- changed_lane: BOOL_DTYPE / np.bool_
- controlled: BOOL_DTYPE / np.bool_

C-contiguity:
- Ensure returned arrays are C-contiguous.
- np.asarray(..., dtype=...).copy() is acceptable where needed.
- Do not return non-contiguous slices.

Overflow note:
- Current dtypes use int16 for lane and length.
- Reject num_lanes values that cannot fit into LANE_DTYPE if needed.
- Reject bus_length values that cannot fit into LENGTH_DTYPE if needed.
- road_length/pos uses int32, so ordinary test values are fine.
- Keep validation simple but do not silently overflow.
