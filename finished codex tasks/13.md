# Timing implementation

Use standard library only.

Recommended implementation:

```python
from time import perf_counter_ns
```

Write helper:

```python
def time_callable(fn, *, repeat: int, warmup: int) -> dict:
    for _ in range(warmup):
        fn()
    samples_ns = []
    for _ in range(repeat):
        start = perf_counter_ns()
        fn()
        end = perf_counter_ns()
        samples_ns.append(end - start)
    return {
        "repeat": repeat,
        "warmup": warmup,
        "samples_ns": samples_ns,
        "min_ns": min(samples_ns),
        "median_ns": statistics.median(samples_ns),
        "mean_ns": statistics.fmean(samples_ns),
        "max_ns": max(samples_ns),
    }
```

Also compute:

```text
min_ms
median_ms
mean_ms
max_ms
vehicles_per_second based on median
cells_per_second based on median where relevant
speedup_vs_kernel_median
speedup_vs_public_median
```

Be careful with division by zero.

Do not assert speedups.

Do not fail because Numba is slower.
